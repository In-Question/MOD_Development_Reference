# 突进模组开发参考

这份手册给后续模组定接入点。机制按函数写在 `Analysis/DashAndAirDashAnalysis.md`。这里只保留改代码时要分清的三条线、每条线动哪个函数、缺省参数，以及已经做过、不必再试的实验。

脚本：

- 技能突进和对敌人的跃击：`DecompiledGameScripts/cyberpunk/player/psm/locomotionTransitions.swift`
- 选目标：同目录 `defaultTransition.swift` 的 `GetTargetObject`
- 近战跃击和近战冲刺：同目录 `meleeTransitions.swift`

状态机连线在 `playerStateMachineLocomotion` 资源里，仓库没有这张图。`EnterCondition` 返回真，只说明这条边如果存在，就可以进。冲量数字是 `GetStaticFloatParameterDefault` 的脚本缺省，节点上的静态参数可以覆盖。

低重力 `DodgeAirLowGravity` 不在这里。头顶下落击杀是 `Takedown` 的 `LeapToTarget`，见 `下落机制分析`。

## 1. 三条突进不要混

| 玩家在做什么 | 状态 | 决策 / 事件 | 位移函数 |
| --- | --- | --- | --- |
| 按闪避键或方向闪避键，买了反应里程碑之后的长突进 | `dodge` | `DodgeDecisions` / `DodgeEvents` | `Dash`，或传统 `Dodge` |
| 同一次突进里准星对着敌人、朝向小于 60° | 仍是 `dodge` | 同上 | `DodgeEvents.LeapToTarget` |
| 近战蓄力松开，朝目标跃过去 | `meleeLeap` | `MeleeLeapDecisions` / `MeleeLeapEvents` | `MeleeLeapEvents.LeapToTarget` |
| 冲刺中按下近战，武器允许冲刺攻击 | `meleeDash` | `MeleeDashDecisions` / `MeleeDashEvents` | `DashToTarget`，否则 `Dash` |

`dodgeAir` 不是上面任何一条。它的问题在第 5 节。买了 `Reflexes_Central_Milestone_2` 的 2 级和 `Reflexes_Central_Milestone_3` 的 3 级之后，人在空中按闪避，走的是 `DodgeEvents.Dash`。

运动黑板 `Locomotion`：站立的 `dodge` 写 7，蹲姿突进写 13，`dodgeAir` 写 8。7 不是优先级。

`GetTargetObject` 是静态函数，不能 `Override`。三条里用到它的地方，都要在调用前改距离，或在调用后换掉拿到的对象。

几个模组同时 `Override` 同一个 `EnterCondition` 时，后加载的那份盖住前一份。`ModExamples/Dash`、`VehicleDodge`、`AirDodge`、`DisableDodgeAir` 不要一起开。

## 2. 技能突进

改地面长突进、空中长突进、同一段滞空只能一次、冲量大小，都在这一节。不要去改 `dodgeAir`，也不要去改 `meleeDash`。

### 2.1 接到哪个函数

| 要改的行为 | 函数 | 约行 |
| --- | --- | --- |
| 闪避键何时算按下 | `DodgeDecisions.OnAction` | 2214 |
| 离地能不能进、冷却、体力、`disableAirDash` | `WantsToDodge` | 262 |
| 时停和瞄准远程武器 | `DodgeDecisions.EnterCondition` | 2224 |
| 从瞄准行走转入 | `AimWalkDecisions.ToDodge` | 1058 |
| 强化还是传统、锁敌还是冲量 | `DodgeEvents.OnEnter` | 2286 |
| 空中冲量、写下 `disableAirDash` | `DodgeEvents.Dash` | 2496 |
| 高度够不够算空中冲量 | `TreatDashAsAirDash` | 2488 |
| 没买里程碑 2，或在电梯里 | `DodgeEvents.Dodge` | 2537 |
| 离开和清理 | `ToStand` / `ToCrouch` / `ToSlide` / `ToFall`，`CleanUpOnExit` | 2243 起，2428 |

`DodgeDecisions.OnAction` 在按下时打开进入检查。松开时把 `m_shouldDisableEnterCondition` 设为真，但当前这一帧仍然判断。`Dodge` 键是 `IsActionJustTapped`，点按在松开那一帧成立。方向键是 `IsActionJustPressed`，还要 `GetMovementDodgeEnabled`。

### 2.2 进入时按这个顺序看

`WantsToDodge` 前面失败就不会看按键：

1. 没有 `HasDodge`。这套运动脚本只读这面旗，不写它
2. `HealFood3`
3. `DodgeCooldown` 或 `DodgeAirCooldown`
4. 人离地，并且里程碑 3 不是 3 级，或体力不大于 0，或 `disableAirDash` 有效且为真
5. 下落快过 `VeryHardLandingFallingSpeed`。人在地上时这条不成立

`EnterCondition` 在这之后还否决：时停原因 `kereznikov` 开着；没有 `CanAimWhileDodging` 且上半身 `aimingState` 且拿着远程武器。

从 `AimWalk` 转入还要里程碑 2 已经是 2 级。蹲伏用 `WantsToDodgeFromCrouch`，瞄准时不要求远程武器。滑行还要 `HasValidDodgeAngle`，缺省 95°。

### 2.3 进去之后

`OnEnter` 先把 `currentNumberOfJumps` 存进成员，再调用 `LocomotionGroundEvents.OnEnter`。父类把跳跃次数和 `currentNumberOfAirDodges` 清 0，并把 `disableAirDash` 写成假。后面的 `Dash` 用的是成员里的旧跳跃次数。

不在电梯且里程碑 2 为 2 级，走强化。否则走传统 `Dodge`：有体力 7.80，耗尽 5.50，减速度修正 -0.71。蹲着不推 `Dodge` 动画。

强化里若人已离地且里程碑 3 不是 3 级，函数直接 `return`。不给冲量，也不做共享收尾。正常从 `WantsToDodge` 进来时这道早退踩不到。

不锁敌就 `Dash`。脚离地时 `disableAirDash = true`。同一段滞空再按，`WantsToDodge` 失败。落地进任意地面状态才清掉。高度绝对值超过 `Perks.IsPlayerInAirDashElevation.elevationThreshold` 时用空中冲量，否则人仍在 `dodge` 里，用地面冲量。

| 档 | 有体力 | 体力为 0 | 减速修正 |
| --- | --- | --- | --- |
| 地面 `dashImpulse` | 10.00 | 7.80 | -0.71 |
| 空中 `airDashImpulse` | 10.00，并挂 `DodgeAirBuff` | 6.50 | -0.71 |
| 传统 `impulse` | 7.80 | 5.50 | -0.71 |

冲量 Z 为 0，消不掉已经有的下落速度。只写一次，按住不补。-0.71 在退出时卸掉。`LandingType` 若已是死亡落地，突进不会清。

共享收尾在早退之后才有：`gmpl_player_dodged`、`IsDodging`、`DodgeBuff`、侧向无敌、扣体力。侧向是朝向小于 -45° 或大于 45°，并且没耗尽。`DodgeBuff` 实机至少 0.2 秒，秒数不在这段脚本里。四个出口谁先被问到，脚本没写。`ToFall` 在时停开着、离地、瞄准、且 `Reflexes_Inbetween_Left_3` 任意等级时返回假。

`OnExit` 先清理再交回父类。`OnForcedExit` 相反。

### 2.4 改的时候

同一段滞空只能长突进一次，是 `Dash` 写的 `disableAirDash`。只改 `currentNumberOfAirDodges` 挡不住它。只改 `WantsToDodge` 也绕不开 `dodgeAir` 自己的次数门，如果那条状态真的被进入了。

`ModExamples/Dash` 改的是这条。空中连发、按住补速度、锁敌射程和伤害那一版已经放弃：按下进、按住不续速；减速仍是进入时那条 -0.71。

## 3. 对敌人发起的突进

仍是状态 `dodge`。人已经进了强化位移，才在 `DodgeEvents.OnEnter` 里选择 `LeapToTarget`（约 2459 行）。不调用 `Dash`，所以不写 `disableAirDash`。

### 3.1 三个条件

1. 准星名牌 `UI_NPCNextToTheCrosshair` 上的对象 `IsHostile()`
2. `AbsF(DodgeDirection) < 60`
3. `GetTargetObject` 在远距或近距里至少有一个有定义。远距缺省 5，`Reflexes_Central_Perk_2_1` 任意等级乘 2。近距缺省 1。第三个参数 `true`，会先找可跃击对象

传给 `LeapToTarget` 的是名牌上的对象，不是 `GetTargetObject` 的返回值。距离门和飞行目标可以不是同一个。

`GetTargetObject`（`defaultTransition.swift` 约 171 行）否决：不是活着的 puppet、态度是 `AIA_Friendly`、距离超出、角度超出（这次调用没传角度）。友好目标进不了距离窗。敌对是名牌上另判的。

### 3.2 位移

镜头朝向。俯仰大于 `noTargetMaxPitch`（缺省 45）夹到 45。向量是目标位置减镜头位置，再缩短 1.25。落点是玩家位置加上这个向量。时长 0.05 到 0.25 秒，按距离在 `minDistToTarget` 1 和 `maxDistToTarget` 5 之间插值。这次读的最大距离不乘专长的 2。短于 1 也走，时长取 0.05。

`RequestPlayerPositionAdjustment` 的目标参数是 `null`，旋转时长 -1。共享收尾仍然执行。

### 3.3 改射程

乘在调用 `GetTargetObject` 之前的那个 `maxDistToTarget` 上。专长已经乘过 2，再乘就是乘在结果上。只加长搜索、不加长 `CalculateAdjustmentDuration` 的上限，更远的目标仍在 0.25 秒里走完。

不要 `Override` `GetTargetObject`。要换目标，在 `OnEnter` 里换传给 `LeapToTarget` 的对象。

## 4. 近战突进

在 `meleeTransitions.swift`。不走 `WantsToDodge`，不写 `disableAirDash`。改闪避突进的模组不要动这里，除非需求就是蓄力跃击或冲刺攻击。

### 4.1 蓄力跃击 `meleeLeap`

`MeleeLeapDecisions.EnterCondition`（约 3271 行）要人在 `meleeChargedHold` 且近战键已经松开。冲刺或水平速度大于 5 时，还要求人在地上。然后：

- 离地要有 `CanMeleeLeapInAir`
- 必须有 `CanMeleeLeap`
- 螳螂刀、间谍攻击旗、武器已蓄力：`CanPerformRelicLeap`，距离改用 `maxDistToTargetMantisBladesRelic`，缺省 40。否则 `maxDistToTarget` 缺省 5
- 缺省不能无目标跃。最大距离内没有目标就拒绝
- `minDistToTarget` 缺省 2 以内已经有目标也拒绝

`FinisherTarget` 有定义时，上面这些距离和旗子都不看，直接进入。

`MeleeLeapEvents.LeapToTarget`（约 3403 行）成功才把黑板 `MeleeLeap` 写成真。俯仰相反数大于 `leapMaxPitch`（缺省 45）失败。`IsTargetReachable` 失败则整次失败。非螳螂刀还有 `leapTargetWithinAngle`，缺省 10°。时长用近战自己的 `CalculateAdjustmentDuration`，缺省上下限都是 1 秒，和运动突进的 0.05 到 0.25 不是同一套缺省。出口时间从时长里减去 `attackStartupDuration`。体力用 `ModifyStaminaBasedOnLeapAttackDistance`。

无目标的 `Leap` 只在 `canLeapWithoutTarget` 为真且锁目标失败时发生。沿镜头前方，缺省 5。

`MeleeChargedHoldEvents.OnEnter` 用 TweakDB `playerStateMachineMelee.meleeLeap.maxDistToTarget` 刷新有效射程。改状态节点上的静态参数，不会自动改这个 TweakDB 值。

### 4.2 冲刺攻击前的 `meleeDash`

`MeleeDashDecisions.EnterCondition`（约 3552 行）：

1. 运动状态是 `sprint`，或人离地且平面速度大于 5，才开始检查
2. 没按近战（重击、轻击、强击、`QuickMelee`）则取消检查
3. 人不在地上：拒绝。所以第 1 步的离地速度留不到后面，空中进不了这条
4. 武器没有 `CanWeaponDash`，或玩家没有 `CanMeleeDash`
5. 武器没有 `MeleeSprintAttack0`
6. `minTargetDistanceToDash`（缺省 2）内已有目标：太近不冲
7. `CheckDashCollision` 前方静态几何不是 `NoGeometry`。查询距离和范围缺省都是 5

`MeleeDashEvents.OnEnter` 先 `DashToTarget`。`maxDistToAquireTarget` 缺省 5。俯仰相反数大于 `dashMaxPitch`（缺省 45）则改走无目标 `Dash`，镜头前方 `noTargetDashDistance` 缺省 5。两路时长都是 `slideDuration`，缺省 0.30 秒，不按距离插值。有目标时 `distanceRadiusToTarget` 缺省 0.90，并带一个 Y 为 2 的安全位移，目标在上方时 Y 取反。

`ToMeleeSprintAttack` 用 `slideDuration` 减 `attackEffectDelay`。这段里的 `attackData` 没有先赋值。改这个出口时间时先确认攻击数据从哪来，不要只改 `slideDuration`。

## 5. dodgeAir：不必再试的做法

`DodgeAirDecisions` / `DodgeAirEvents`。运动黑板 8。常规操作没有独立用途。正式关掉它用 `ModExamples/DisableDodgeAir`，只让 `EnterCondition` 返回假。低重力和状态 `dodge` 不动。

已经定过的问题：

1. 闪避键对不齐。检查在按下那一帧打开并立刻关掉，点按要到松开才成立。实机人在 `doubleJump`：`JustPressed=true`，`JustTapped=false`。松开进的是 `dodge`。
2. 离地要里程碑 3 为 3 级，那是共用的 `WantsToDodge`。`DodgeAirEvents.Dodge` 不读等级。冲量缺省 10，不挂 -0.71。强行让另一条返回假之后进去了，手感接近传统闪避。
3. 进入不读 `kereznikov`。另一条在这道门返回假时，状态机可以改走它。这不说明它是时停专用的另一档突进。`ToFall` 离开时才看时停。
4. `HasDodgeAir` 在反编译脚本里没有赋值。`EnterCondition` 看 `HasStatFlag`。终端对这个名字加 Additive 改的是数值。后来日志仍是旗 `false`、数值 `0.00`。

不必再做：

- 不要再在 CET 里开关 `HasDodgeAir` 的数值，然后期望空中长突进出现。长突进不看这面旗。
- 不要把「不买 3 级进不去」和「买了 3 级就被另一条吃掉 `HasDodge`」当成死锁。运动脚本不写 `HasDodge`。等级 2 时停在 `WantsToDodge`。升到 3 级后，松开帧进 `dodge` 是点按窗口的问题。
- 不要在人已经处于 `dodge` 时再按 `DodgeForward`。当时黑板是 `Dodge(7)`，`EnterCondition` 不会执行。
- 不要再做一次「拒绝另一条的 kereznikov 门，看 `dodgeAir` 手感」。那次已经通过，手感就是基础突进。

还没做成的一次：人在 `fall` 或 `jump`，`HasDodge` 还在，还没进 `dodge`，双击方向键。不要同时开着 `AirDodge` 里「空中拒绝 `DodgeDecisions`」的那段，否则看不出原脚本自己选谁。忽略 `HasDodgeAir` 仍然需要，否则第一行就返回假。

`ModExamples/AirDodge` 是实验补丁。不要和 `Dash`、`VehicleDodge`、`DisableDodgeAir` 一起开。

## 6. 改之前对一下的参数

这些缺省都在调用 `GetStaticFloatParameterDefault` 的那个状态节点上。近战和运动突进同名参数不是同一份。

| 参数 | 谁在读 | 缺省 |
| --- | --- | --- |
| `dashImpulse` / `dashImpulseNoStamina` | `DodgeEvents.Dash` 地面档 | 10 / 7.80 |
| `airDashImpulse` / `airDashImpulseNoStamina` | `DodgeEvents.Dash` 空中档 | 10 / 6.50 |
| `impulse` / `impulseNoStamina` | `DodgeEvents.Dodge` | 7.80 / 5.50 |
| `impulse` | `DodgeAirEvents.Dodge` | 10，无减速修正 |
| `dashMovementDecelerationModifier` | 传统闪避和地面 `Dash` | -0.71 |
| `airDashMovementDecelerationModifier` | 空中档 `Dash` | -0.71 |
| `maxDistToTarget` / `minDistToTarget` | `DodgeEvents` 搜索 | 5 / 1。专长只乘搜索时的最大距离 |
| `minAdjustmentDuration` / `maxAdjustmentDuration` | `DodgeEvents.CalculateAdjustmentDuration` | 0.05 / 0.25。这里的最大距离不乘专长 |
| `maxDistToTarget` / `minDistToTarget` | `MeleeLeapDecisions` | 5 / 2。遗物档最大 40 |
| `maxDistToTarget` | `MeleeLeapEvents.CalculateAdjustmentDuration` | 脚本缺省 1，时长缺省也是 1 到 1 |
| `minTargetDistanceToDash` | `MeleeDashDecisions` | 2。以内有目标则不进 |
| `maxDistToAquireTarget` / `slideDuration` | `MeleeDashEvents` | 5 / 0.30 |
| `numberOfAirDodges` | `DodgeAirDecisions` | 1 |

`playerStateMachineMelee.meleeLeap.maxDistToTarget` 是 TweakDB，蓄力开始时用来刷新有效射程。`playerStateMachineLocomotion.dodge.dashOnePunchAttackEnemyMaxRange` 是拳套另一条，不是闪避跃击的搜索距离。
